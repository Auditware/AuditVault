## Report summary

Subdomain takeover possible on one of Starbucks's subdomain. The subdomain pointed to Microsoft Azure Cloud App which was no longer registered under Azure.

Detailed write-up: https://0xpatrik.com/subdomain-takeover-starbucks/

- **2018-03-13** @0xpatrik: Hello,

I have provided the PoC link (which is the starbucks.com domain itself) which states "Subdomain takeover PoC" along with my name. I can upload a specific string or file to the domain if that helps, but I hope it is clear now that I can have a full access with current the PoC. Step by step actions that I took:

1. .cloudapp.net subdomains are provided by "Cloud Services" in Azure portal (https://azure.microsoft.com/en-us/services/cloud-services/). You can create a new Cloud Service and choose the subdomain name which I matched with 1fd05821-7501-40de-9e44-17235e7ab48b.cloudapp.net.
2. I created a Storage Account for the Cloud Service in Azure portal.
3. Azure requires specific format for deployment of Cloud Services which is generated by Visual Studio. I created a simple ASP.NET web application and uploaded it to this Cloud Service (https://docs.microsoft.com/en-us/azure/cloud-services/cloud-services-how-to-create-deploy-portal).
4. Because of DNS, the A record for svcgatewayus.starbucks.com is pointing to Azure and so the HTTP request returns the content from the ASP.NET application I just deployed.

Let me know if further specification is needed.

Thank you.
